## 🎯 **기본 사용법**

### **📱 상태 배너 사용법**

Git-KR을 설치하면 GitHub 페이지 상단에 아름다운 배너가 나타납니다:

```
┌─────────────────────────────────────────────────────────┐
│ 🇰🇷 Git-KR  |  😴 번역 중지 [OFF]  |  🔗 서버 연결됨     │
└─────────────────────────────────────────────────────────┘
```

**배너 구성 요소**:

- **🇰🇷 Git-KR**: 프로젝트 로고
- **😴 모드 표시**: 현재 번역 모드와 상태
- **🔗 서버 상태**: AI 서버 연결 상태

### **⚡ 원클릭 모드 전환**

**배너 중앙 클릭**하면 모드가 순환적으로 변경됩니다:

```
😴 OFF → 📚 LOCAL → 🤖 AI → 😴 OFF → ...
```

**실시간 변경**: 클릭 즉시 모든 탭에서 동시 적용!

### **🎛️ 팝업 컨트롤 패널**

**확장프로그램 아이콘 클릭**하면 상세 컨트롤 패널이 열립니다:

```
┌─────────────────────────────────┐
│        🇰🇷 Git-KR              │
├─────────────────────────────────┤
│ 📊 번역 통계                    │
│ • 총 번역: 1,247개              │
│ • 캐시 히트: 94%                │
│ • 평균 속도: 0.12초             │
├─────────────────────────────────┤
│ 🎯 번역 모드                    │
│ ○ 😴 OFF    - 번역 중지         │
│ ○ 📚 LOCAL  - 기본 사전         │
│ ● 🤖 AI     - 최고 품질         │
├─────────────────────────────────┤
│ 🔗 서버 상태: ✅ 연결됨         │
│ 📡 응답 속도: 89ms              │
└─────────────────────────────────┘
```

## 🎯 **3단계 모드 시스템**

Git-KR의 핵심 혁신인 3단계 모드를 상세히 알아보겠습니다.

### **😴 OFF 모드 - 완전 중지**

**언제 사용**: 원본 영어로 집중 작업이 필요할 때

**동작 방식**:

- ✅ **완전 중지**: 모든 번역 중지
- ✅ **원본 복구**: 번역된 텍스트를 100% 원본으로 되돌림
- ✅ **메모리 정리**: 불필요한 감지 프로세스 중단
- ✅ **성능 향상**: CPU 사용량 0%로 감소

**사용 시나리오**:

- 📝 중요한 문서 작성시
- 🔍 영어 학습이 목적일 때
- ⚡ 최고 성능이 필요할 때
- 🎯 원본 UI에 집중하고 싶을 때

### **📚 LOCAL 모드 - 안정적 기본 번역**

**언제 사용**: 안정적이고 빠른 번역이 필요할 때

**동작 방식**:

- ✅ **오프라인 작동**: 인터넷 없어도 동작
- ✅ **검증된 번역**: 확실한 GitHub 용어만 번역
- ✅ **빠른 성능**: 로컬 사전으로 즉시 번역
- ✅ **안정성**: AI 서버 장애와 무관하게 동작

**번역 우선순위**:

1. **사용자 정의 단어** (최우선)
2. **GitHub 핵심 사전** (repository, issue, pull request 등)
3. **일반 프로그래밍 용어** (user, settings, profile 등)

**사용 시나리오**:

- 💼 업무 환경에서 안정성 중요시
- 🌐 인터넷 연결이 불안정할 때
- ⚡ 최고 속도가 필요할 때
- 🔒 보안이 중요한 환경

### **🤖 AI 모드 - 최고 품질 번역**

**언제 사용**: 최고 품질의 완전한 번역이 필요할 때

**동작 방식**:

- ✅ **Google AI 번역**: 최신 AI 기술 활용
- ✅ **문맥 인식**: 단어가 아닌 문장 단위 번역
- ✅ **새 기능 대응**: GitHub 업데이트 즉시 번역
- ✅ **자연스러운 한글**: 읽기 편한 번역 결과

**번역 우선순위**:

1. **사용자 정의 단어** (최우선)
2. **Google AI 번역** (새로운 텍스트)
3. **GitHub 후처리**: GitHub 특화 용어로 보정
4. **로컬 사전**: AI 실패시 fallback

**사용 시나리오**:

- 🎓 GitHub 학습 및 탐색시
- 🔍 새로운 기능 이해가 필요할 때
- 📚 오픈소스 프로젝트 분석시
- 🌟 최고 품질 번역 경험 원할 때

## 👤 **사용자 정의 단어 관리**

개인 취향이나 회사 표준에 맞게 번역을 커스터마이징하세요!

### **🔧 단어 추가 방법**

**1단계**: 옵션 페이지 열기

- **확장프로그램 아이콘 우클릭** → "옵션" 선택

**2단계**: 단어 추가

```
┌─────────────────────────────────────────────┐
│ 🇰🇷 Git-KR 사용자 정의 단어                 │
├─────────────────────────────────────────────┤
│ English Word    │ Korean Translation        │
├─────────────────┼─────────────────────────┤
│ repository      │ 저장소                   │
│ username        │ 사용자명                 │
│ workflow        │ 워크플로우               │
├─────────────────┼─────────────────────────┤
│ [새 단어 입력]   │ [한글 번역 입력]         │
│                 │              [추가] 버튼  │
└─────────────────────────────────────────────┘
```

**3단계**: 즉시 적용

- **저장 버튼 클릭** → 모든 GitHub 탭에서 즉시 적용!

### **📝 단어 관리 기능**

**✏️ 수정**: 기존 단어 클릭 → 번역 수정 → 저장

**🗑️ 삭제**: 단어 옆 🗑️ 버튼 클릭

**📤 내보내기**: 설정을 JSON 파일로 백업

```json
{
  "repository": "저장소",
  "username": "사용자명",
  "workflow": "워크플로우"
}
```

**📥 가져오기**: 백업 파일에서 설정 복원

### **💡 추천 사용자 정의 단어**

**회사 표준 용어**:

```
organization → 조직
member → 구성원
admin → 관리자
team → 팀
```

**개인 취향 반영**:

```
repository → 리포지토리 (저장소 대신)
commit → 커밋
branch → 브랜치
merge → 머지 (병합 대신)
```

**프로젝트 특화 용어**:

```
deployment → 배포
pipeline → 파이프라인
artifact → 아티팩트
environment → 환경
```

## 🔄 **Git-KR이 작동하는 과정**

### **📚 번역 사전이 2곳에 나눠진 이유**

```
📁 assets/glossary.json (클라이언트용)
├─ Chrome 확장프로그램에서 직접 사용
├─ LOCAL 모드에서 활용
└─ 오프라인에서도 동작

📁 server/app.py (서버용, 하드코딩)
├─ Google AI 번역 후처리용
├─ GitHub 특화 용어 보정
└─ 더 풍부한 1000+ 단어
```

**왜 2곳으로 나눈을까?**

- **성능**: 클라이언트는 필수 단어만, 서버는 전체 사전
- **독립성**: 서버가 꺼져도 기본 번역은 동작
- **유지보수**: 각각 다른 목적으로 최적화

### **🎯 "번역 우선순위" - 사용자 설명 버전**

"간단하게 보면 ai번역 들어가면 로컬번역이 지금 2개로 나눠져있어요"

```
"repository" 단어를 발견했을 때:

1순위: 사용자 정의 단어 확인
  → Chrome Storage에서 userGlossary 검색
  → 있으면 즉시 사용! 없으면 다음 단계

2순위: 로컬 사전 확인 (2곳)
  ├─ assets/glossary.json 확인
  └─ 없으면 다음 단계

3순위: 이전 번역 기록 확인 (캐시)
  → translationCache["repository"] 검색
  → 있으면 즉시 사용! 없으면 다음 단계

4순위: AI 서버에 번역 요청
  → POST http://localhost:5001/translate
  → {"text": "repository"}
  → 서버에서 처리:
    ├─ app.py의 하드코딩 사전 먼저 확인
    ├─ 없으면 Google Translate API 호출
    ├─ GitHub 특화 용어로 후처리
    └─ 결과: "저장소"

5순위: 모든 캐시에 결과 저장
  ├─ 서버 메모리 캐시
  ├─ 클라이언트 메모리 캐시
  └─ 브라우저 localStorage

6순위: DOM에 번역 결과 적용
  "repository" → "저장소"로 화면 변경!
```

**"로컬번역쪽 먼저확인하고 캐시 확인해서 번역된게 없으면 구글ai로 번역하고 캐시에 저장해서 출력하는거에요"**

### **🏠 상세한 초기화 과정**

```
사용자가 github.com 방문
    ↓
Chrome이 manifest.json 확인
    ↓
content.js가 GitHub 페이지에 주입
    ↓
설정 로드 (마지막 사용한 모드 등)
    ↓
AI 서버 연결 상태 확인 (health check)
    ↓
상태 배너 화면 상단에 생성
    ↓
현재 모드에 따라 번역 시작 여부 결정
```

### **🔍 번역 대상 발견 과정**

```
TreeWalker가 DOM 전체 스캔
    ↓
텍스트 노드만 선별적 수집
    ↓
번역 가치 있는 텍스트인지 판단:
  ✅ 영어 텍스트
  ✅ 의미있는 길이 (1-200자)
  ❌ 이미 한글 포함
  ❌ 숫자나 특수문자만
    ↓
번역 대상 리스트 생성: ["repository", "issue", "pull request"]
```

### **🎆 실제 사용 예시 - 월요일 아침**

```
개발자가 출근해서 GitHub Issues 확인
    ↓
Git-KR 배너가 "LOCAL 모드" 표시
    ↓
"Issue #123: Fix repository settings"
    → "이슈 #123: 저장소 설정 수정" 으로 번역
    ↓
안정적이고 빠른 번역으로 업무 효율 UP!
```

## 🚀 **고급 기능**

### **⚡ 배치 번역 최적화**

Git-KR은 지능적으로 번역을 최적화합니다:

**자동 배치 감지**:

- 5개 이상 번역할 텍스트 발견시 자동으로 배치 모드
- 개별 요청 대신 한 번의 API 호출로 처리
- 네트워크 지연 최소화

**성능 향상 효과**:

```
개별 번역: 5개 × 200ms = 1000ms (1초)
배치 번역: 1개 × 300ms = 300ms (0.3초)
→ 70% 성능 향상! ⚡
```

### **🧠 4층 캐시 시스템**

**1층 - 메모리 캐시** (0.001초):

- 현재 세션 동안 즉시 접근
- 가장 빠른 번역 속도

**2층 - 브라우저 저장소** (0.01초):

- 브라우저 재시작 후에도 유지
- 최대 1000개 항목 저장

**3층 - AI 서버 캐시** (0.1초):

- 다른 사용자와 번역 결과 공유
- 팀 환경에서 효율성 극대화

**4층 - Google API** (1-3초):

- 완전히 새로운 텍스트만 요청
- 비용 및 지연 최소화

### **🔄 실시간 동기화**

**크로스탭 동기화**:

- 여러 GitHub 탭에서 동일한 설정 공유
- 한 탭에서 모드 변경시 모든 탭에 즉시 반영

**설정 동기화**:

- 사용자 정의 단어 실시간 공유
- Chrome 프로필별 독립적 설정

**상태 동기화**:

- 배너 ↔ 팝업 양방향 실시간 동기화
- 서버 연결 상태 모든 곳에서 동시 표시

### **🔒 완전한 원본 복구**

**WeakMap 기반 추적**:

- 메모리 효율적으로 원본 텍스트 보존
- 가비지 컬렉션 친화적 설계

**100% 복구 보장**:

- OFF 모드시 모든 번역을 원본으로 되돌림
- 번역 흔적 완전 제거
- GitHub 원본 상태와 동일

## 💡 **팁과 트릭**

### **🎯 효율적인 모드 전환**

**상황별 최적 모드**:

```
😴 OFF:    코드 리뷰, 영어 학습, 성능 중시
📚 LOCAL:  일상 업무, 안정성 중시, 오프라인
🤖 AI:     새 프로젝트 탐색, 최고 품질 원함
```

**빠른 전환 꿀팁**:

- **스페이스바**: 배너에 포커스된 상태에서 모드 전환
- **키보드 단축키**: `Ctrl+Shift+K` (커스터마이징 가능)

### **📊 성능 모니터링**

**팝업에서 확인 가능한 지표**:

- **번역 통계**: 총 번역 횟수, 성공률
- **캐시 히트율**: 얼마나 효율적으로 캐시 활용중인지
- **평균 응답 속도**: AI 서버 성능 모니터링
- **메모리 사용량**: 확장프로그램 리소스 사용량

### **🔧 문제 상황 대처**

**AI 서버 연결 실패시**:

- 자동으로 LOCAL 모드로 전환
- 배너에 "⚠️ 서버 연결 끊어짐" 표시
