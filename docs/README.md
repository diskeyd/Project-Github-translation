## 🆚 **기존 vs Git-KR: 완전히 다른 차원**

### **기존 github-ko-ext (2021년 중단)**

- 정적 텍스트 치환만 가능

## ✨ **혁신적 핵심 기능**

### 🤖 **왜 Google AI를 선택했을까?**

- **🏆 검증된 품질**: 수억 명이 사용하는 신뢰할 수 있는 번역 서비스
- **💰 합리적 비용**: 월 50만자까지 무료, 그 이후 저렴한 종량제
- **🔧 GitHub 특화**: 프로그래밍 용어와 개발 문맥을 정확히 이해
- **📈 지속 개선**: Google이 알아서 모델 업데이트로 품질 향상

### 🎯 **똑똑한 4단계 번역 우선순위**

```
1순위: 사용자 정의 단어 (개인 취향 100% 반영)
    ↓ (없으면)
2순위: 검증된 GitHub 사전 (안전하고 확실)
    ↓ (없으면)
3순위: 이전 번역 기록 (0.001초 초고속)
    ↓ (없으면)
4순위: Google AI 새 번역 (최고 품질)
```

- **새로운 GitHub 기능**도 즉시 번역
- **문맥 인식** 번역으로 자연스러운 한글
- **학습하는 시스템**: 사용할수록 더 빨라지고 정확해짐

### 🎯 **3단계 지능형 모드 시스템**

```
😴 OFF    ⟨ 완전 중지 + 원본 복구 (집중 모드)
📚 LOCAL  ⟨ 안전한 사전 번역 (오프라인 모드)
🤖 AI     ⟨ 최고 품질 AI 번역 (학습 모드)
```

**상황별 최적화**: 업무시 LOCAL, 학습시 AI, 집중시 OFF

### 📡 **실시간 상태 동기화**

- **배너 ↔ 팝업** 양방향 동기화
- **모든 GitHub 탭**에서 동일한 설정
- **1초 내 즉시 반영** 되는 모드 변경

### ⚡ **4층 캐시 성능 최적화**

| 캐시 층         | 속도    | 특징               |
| --------------- | ------- | ------------------ |
| 🧠 **메모리**   | 0.001초 | 즉시 접근          |
| 💾 **브라우저** | 0.01초  | 재시작 후에도 유지 |
| 🖥️ **서버**     | 0.1초   | 다른 사용자와 공유 |
| 🤖 **AI API**   | 1-3초   | 새로운 번역만      |

**결과**: 같은 단어 두 번째부터는 **100배 빠른** 번역 속도!

### 👤 **완전한 개인화**

- **사용자 정의 단어**: "repository" → "저장소" 직접 추가
- **회사 전용 용어**: 팀 표준 번역 적용
- **최우선 적용**: AI보다 개인 설정이 우선

## 🚀 **3분 만에 시작하기**

### **1단계: 확장프로그램 설치** ⚡

```bash
Chrome 확장프로그램 페이지 열기 → 개발자 모드 ON → 폴더 로드
```

👉 **[상세 설치 가이드](SETUP.md)**

### **2단계: AI 서버 실행** (선택사항) 🤖

```bash
docker run -p 5001:5001 git-kr-server
```

👉 **[서버 구동 가이드](../server/README.md)**

### **3단계: GitHub에서 확인** ✅

1. GitHub 방문 → 페이지 새로고침
2. 상단 배너: `😴 번역 중지 [OFF]` 확인
3. 배너 클릭 → `🤖 AI 번역 [ON]` 선택
4. **번역 완료!** 🎉

**서버 없어도 OK**: 기본 사전으로도 충분한 번역 제공 ✅

## 🎮 **스마트한 사용법**

### **📱 원클릭 모드 전환**

화면 상단 아름다운 배너를 클릭하여 즉시 변경:

```
😴 OFF 모드     ⟨ 원본 영어로 집중 작업
📚 LOCAL 모드   ⟨ 안정적 한글화 (오프라인)
🤖 AI 모드      ⟨ 최고 품질 번역 (온라인)
```

### **👤 나만의 번역 사전**

확장프로그램 우클릭 → 옵션에서 단어 추가:

```
English: username
Korean:  사용자명
```

즉시 적용되어 모든 "username"이 "사용자명"으로 번역!

## 🌟 **Git-KR만의 특별함**

### **🔒 왜 이렇게 복잡하게 설계했을까?**

**🛡️ 안정성 보장**

- AI 서버가 고장나도 로컬 사전으로 기본 번역 지속
- 인터넷이 끊어져도 캐시된 번역들은 즉시 표시
- Google API 할당량이 다 떨어져도 문제없이 사용

**⚡ 성능 극대화**

- 같은 단어를 매번 새로 번역하는 건 비효율적
- 한 번 번역한 건 기억해뒨다가 즉시 재사용
- 여러 단어를 한께번에 번역해서 속도 향상

**👤 개인화 지원**

- "사람마다 선호하는 번역이 다르잖아"
- "repository"를 "저장소" vs "리포지토리" 중 선택 가능
- 회사에서 쓰는 용어로 통일 가능

### **🔒 완전한 원본 복구**

- WeakMap 기반 메모리 효율적 추적
- OFF 모드시 100% 원본 상태로 복구
- 번역 흔적 완전 제거

### **📈 지능형 최적화**

- 배치 번역으로 네트워크 최적화
- 디바운스로 불필요한 재스캔 방지
- 메모리 효율적 캐싱 시스템
