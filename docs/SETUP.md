# 📥 **Git-KR 설치 가이드**

> **Chrome 확장프로그램 설치부터 첫 번역까지 완벽 가이드**

---

## 🎯 **설치 개요**

Git-KR 설치는 **2단계**로 구성됩니다:

1. **📱 Chrome 확장프로그램 설치** (필수, 5분)
2. **🖥️ AI 서버 실행** (선택사항, 최고 품질 원할 때)

서버 없어도 기본 사전으로 충분히 사용 가능합니다! ✅

---

## 🔧 **시스템 요구사항**

### **필수 요구사항**

- **Chrome 브라우저** 88 이상 (또는 Chromium 기반 브라우저)
- **macOS 10.15+** / **Windows 10+** / **Linux Ubuntu 18.04+**
- **메모리**: 최소 4GB (8GB 권장)

### **AI 서버용 요구사항** (선택사항)

- **Python 3.8+** 또는 **Docker**
- **인터넷 연결** (Google Translate API 사용)
- **메모리**: 추가 2GB (서버용)

---

## 📱 **1단계: Chrome 확장프로그램 설치**

### **1.1 프로젝트 다운로드**

**Option A: Git Clone (권장)**

```bash
git clone https://github.com/diskeyd/Project-Github-translation.git
cd Project-Github-translation
```

**Option B: ZIP 다운로드**

1. GitHub 페이지에서 `Code` → `Download ZIP`
2. 적당한 폴더에 압축 해제

### **1.2 Chrome 개발자 모드 활성화**

1. **Chrome 브라우저 열기**
2. **주소창에 입력**: `chrome://extensions/`
3. **우상단 "개발자 모드" 토글 ON** 🔘

<details>
<summary>📸 스크린샷으로 보기</summary>

```
chrome://extensions/ 페이지에서:

┌─────────────────────────────────────┐
│ 확장 프로그램                        │
│                     개발자 모드 🔘   │ ← 이거 켜기!
└─────────────────────────────────────┘
```

</details>

### **1.3 확장프로그램 로드**

1. **"압축해제된 확장 프로그램 로드" 버튼 클릭**
2. **Git-KR 프로젝트 폴더 선택** (manifest.json이 있는 폴더)
3. **"폴더 선택" 클릭**

✅ **성공시**: Git-KR 확장프로그램이 목록에 나타남

<details>
<summary>🐛 설치 실패시 문제 해결</summary>

**❌ "Manifest file is missing or unreadable"**

- `manifest.json` 파일이 있는 폴더를 선택했는지 확인
- 하위 폴더가 아닌 **루트 폴더**를 선택해야 함

**❌ "Extension failed to load"**

- Chrome 브라우저를 완전히 종료 후 재시작
- 개발자 모드가 활성화되어 있는지 재확인

**❌ "Permissions error"**

- 폴더 읽기 권한이 있는지 확인
- 폴더를 Documents나 Desktop으로 이동 후 재시도

</details>

### **1.4 권한 승인**

설치 후 Chrome이 요청하는 권한들:

- ✅ **`github.com` 접근**: GitHub 페이지 번역을 위해 필요
- ✅ **`activeTab`**: 현재 탭 정보 확인용
- ✅ **`storage`**: 설정 및 캐시 저장용
- ✅ **`http://localhost:5001/*`**: AI 서버 통신용 (선택사항)

**모든 권한 승인 클릭** → 설치 완료! 🎉

---

## ✅ **2단계: 설치 확인**

### **2.1 확장프로그램 아이콘 확인**

- Chrome 우상단에 **🇰🇷 아이콘** 표시됨
- 아이콘이 안 보이면 **퍼즐 조각 아이콘** 클릭 → Git-KR 고정

### **2.2 GitHub에서 테스트**

1. **GitHub 방문**: https://github.com
2. **페이지 새로고침** (F5 또는 Cmd+R)
3. **상단 배너 확인**: `😴 번역 중지 [OFF]` 메시지가 나타남

✅ **성공**: 배너가 보이면 설치 완료!

### **2.3 첫 번역 테스트**

1. **배너 클릭**: `😴 OFF` → `📚 LOCAL` 으로 변경
2. **즉시 번역 시작**: "Repository" → "저장소" 등으로 변경됨
3. **팝업 확인**: 확장프로그램 아이콘 클릭해서 상태 확인

🎉 **축하합니다! Git-KR 설치 완료!**

## 🖥️ **3단계: AI 서버 실행** (선택사항)

> 최고 품질 번역을 원한다면 AI 서버를 실행하세요.  
> 서버 없어도 LOCAL 모드로 충분히 사용 가능합니다!

**상세한 서버 설치는**: 👉 **[서버 구동 가이드](../server/README.md)** 참고

**빠른 실행 (Docker 사용시)**:

```bash
cd git-kr/server
docker build -t git-kr-server .
docker run -p 5001:5001 git-kr-server
```

**서버 실행 확인**:

```bash
curl http://localhost:5001/health
# ✅ {"status": "healthy"}
```

## ⚙️ **4단계: 초기 설정**

### **4.1 기본 모드 설정**

**확장프로그램 아이콘 클릭** → 팝업에서:

- **😴 OFF**: 번역 완전 중지 (원본 영어)
- **📚 LOCAL**: 기본 사전 번역 (안정적, 오프라인)
- **🤖 AI**: AI 번역 (최고 품질, 온라인 필요)

**권장**: 먼저 `📚 LOCAL` 모드로 시작하세요!

### **4.2 사용자 정의 단어 추가** (선택사항)

1. **확장프로그램 아이콘 우클릭** → "옵션"
2. **단어 추가**:
   ```
   English: repository
   Korean:  저장소
   ```
3. **저장** → 즉시 적용됨

### **4.3 고급 설정**

**팝업에서 확인 가능한 설정들**:

- 🔗 **서버 연결 상태**: 초록불/빨간불로 표시
- 📊 **번역 통계**: 총 번역 횟수 및 캐시 히트율
- ⚡ **성능 모드**: 배치 번역 활성화/비활성화

## 🔧 **문제 해결**

### **자주 발생하는 문제들**

#### **❌ 배너가 안 보여요**

```bash
# 해결책:
1. GitHub 페이지 새로고침 (F5)
2. 확장프로그램 비활성화 후 재활성화
3. Chrome 재시작
```

#### **❌ 번역이 안 돼요**

```bash
# 체크리스트:
□ 배너에서 모드가 OFF가 아닌지 확인
□ GitHub 페이지가 완전히 로드되었는지 확인
□ 다른 번역 확장프로그램과 충돌 없는지 확인
```

#### **❌ 팝업이 안 열려요**

```bash
# 해결책:
1. chrome://extensions/에서 Git-KR 상태 확인
2. "오류" 버튼이 있다면 클릭해서 오류 확인
3. 확장프로그램 삭제 후 재설치
```

#### **❌ 설정이 저장 안 돼요**

```bash
# 확인사항:
□ Chrome의 확장프로그램 권한이 모두 승인되었는지
□ 시크릿 모드에서는 설정이 별도 저장됨
□ 다른 Chrome 프로필과 설정이 별도임
```

### **고급 문제 해결**

#### **개발자 도구 활용**

1. **F12** 키로 개발자 도구 열기
2. **Console 탭**에서 에러 메시지 확인
3. **오류 메시지**를 GitHub Issues에 신고

#### **로그 확인**

```bash
# Chrome 확장프로그램 로그:
chrome://extensions/ → Git-KR → "오류" 버튼 클릭

# 실시간 로그 확인:
개발자 도구 → Console → "Git-KR" 필터
```

#### **완전 초기화**

```bash
# 모든 설정 초기화:
1. chrome://extensions/에서 Git-KR 삭제
2. 브라우저 완전 종료
3. 프로젝트 폴더 새로 다운로드
4. 처음부터 재설치
```
